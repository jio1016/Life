# LIFE — After the Last Day

작은 마을을 무대로 살아가는 한국어 좀비 아포칼립스 생활 시뮬레이터.

## 실행
GitHub Pages를 켜면 브라우저에서 플레이할 수 있습니다.
- 저장소 Settings → Pages
- Build and deployment에서 Deploy from a branch 선택
- Branch: main / Folder: /(root) 선택 후 Save
- 잠시 기다린 뒤 Pages 주소에서 실행

## 현재 기능
- 캐릭터 생성 및 무작위 캐릭터 설정
- 이름, 나이, 성별, 직업, 성격, 특기, 외모, 과거 설정
- 마을 내 9개 장소 이동
- 탐색, 휴식, 식사, 물 마시기, 주민 대화 및 물물교환
- 건강, 허기, 갈증, 피로, 기분 상태
- NPC와 관계 수치
- 브라우저 로컬 저장 및 이어하기

진행 상황은 사용 중인 브라우저의 localStorage에 저장됩니다.
