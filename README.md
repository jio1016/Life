# LIFE — After the Last Day

2030년 서울 동부권을 무대로 살아가는 한국어 좀비 아포칼립스 생활 시뮬레이터.

## 실행
GitHub Pages를 켜면 브라우저에서 플레이할 수 있습니다.
- 저장소 Settings → Pages
- Build and deployment에서 Deploy from a branch 선택
- Branch: main / Folder: /(root) 선택 후 Save
- 잠시 기다린 뒤 Pages 주소에서 실행

## 현재 기능
- 캐릭터 생성 및 외모 설정에 따른 자동 픽셀 초상화
- 청량리 안전구역을 중심으로 서울 동부권 탐험
- 2030년 서울 지도 일러스트와 지역별 이동
- NPC 첫 만남별 전용 이벤트 및 선택지
- 아직 만나지 않은 NPC 정보 비공개
- 감염자 조우와 턴제 전투 이벤트
- 탐색, 휴식, 식사, 물 마시기, 주민 대화 및 물물교환
- 아이템 사용 및 제작
- 건강, 허기, 갈증, 피로, 감염, 스트레스, 트라우마, 카르마
- 행동별 분 단위 시간 경과 및 브라우저 저장/이어하기
